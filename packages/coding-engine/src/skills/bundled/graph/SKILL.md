---
name: graph
description: Manage the project knowledge graph
---

Manage the knowledge graph for this project. Available subcommands:
- `/graph status` — Show graph stats and health
- `/graph init` — Build the graph for the first time (no-op if already exists)
- `/graph rebuild` — Rebuild the graph from scratch (pure TypeScript, no Python required)
- `/graph update` — Update graph with recent changes
